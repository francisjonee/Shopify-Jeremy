# `Shopify-Jeremy` is public, unlike every other project repo

Every other repo on the account is private. This one is public.

**Why it matters:** Anything committed here is readable by anyone, forever. A token, a
customer email, or a store identifier in a commit cannot be taken back — GitHub keeps
deleted commits.

**How to apply:** Read every diff before committing. Names of environment variables are
fine; values never are. If Francis wants it private, that is a one-line change he makes
on GitHub — worth asking, since it does not match the rest of his setup.
